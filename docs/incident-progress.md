# Incident Agent 当前完成度（2026-10-03）

## 结论

第一版可演示业务闭环已跑通：浏览器选告警 → DeepSeek 官方真实模型调查 → 查询 MCP 证据 → 校验并保存报告 → 模型提出固定处置提案 → 浏览器审批/拒绝 → 合成规则模拟与持久化。不能把它描述为生产部署或真实自动回滚系统。

## 已实现

- 复用 Craft Agents 0.11.4，独立工作区和本地模型配置；浏览器演示入口。
- 3个合成订单故障案例：连接池配置回归、下游超时且存在无关发布、关键观测缺失。
- 11个 stdio MCP 工具：案例、调查建立、5类观测、报告提交、记录查询、动作目录、处置提案。
- 证据 ID、服务、环境、来源、观测时间和检索时间；SQLite 保存实际返回证据、工具结果、报告和审批。
- 拒绝未读取/伪造/跨调查引用；首要候选原因至少由两类当前来源支持；历史不计数；不足时保留缺失项。
- 报告页面查看候选原因、影响、正反证据、未知项和原始观测。
- 不可变固定动作提案；仅浏览器审批入口；模型无审批或执行工具；证据不足仅可补证。
- 审批与模拟结果原子保存，同一决定幂等，拒绝不能反转；错误动作返回无改善；补证不伪造原观测。
- 登录与同源审批校验；本机密钥导入现有加密凭据存储；默认选择已配置的模型。
- 三案例离线结构评测脚本、真实浏览器验收记录及截图。

## 尚未覆盖与范围限制

- 百炼 qwen3.7-plus 已通过一个配置回归案例的真实调查、报告保存与待审批提案；尚未验证其他案例或 qwen3.8-flash。Token Plan套餐使用范围仍需遵守官方约束。
- 无真实Prometheus/Loki/Jaeger/Kubernetes接入；无真实服务压测、生产部署、自动回滚。
- 模拟器是预设规则，不是可运行订单系统或真实恢复指标。告警查询仍是原时刻的不可变快照。
- 尚无足量历史故障集、重复多次基准、统计准确率/耗时收益、专门注入攻击评测。
- 本地单用户鉴权，不是多租户RBAC；没有OS级模型沙箱，Prompt规则不作为硬隔离。
- 调查日志记录业务工具观测和决定，不宣称完整模型推理可审计。
